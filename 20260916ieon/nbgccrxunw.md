# 11岁男孩确诊肺癌！警惕！看不见的“三手烟”

> 更新时间：2026-09-16 (UTC+8)

**点击蓝字 关注我们**

近日，河南郑州11岁男孩反复发烧咳嗽，就医后查出肺恶性肿瘤，确诊肺癌！医生追问病史发现，男孩父亲长期在家吸烟，孩子被迫吸二手烟长达数年。目前，男孩正在医院积极接受治疗当中。

许多人意识到“一手烟”和“二手烟”的危害，于是抽烟时会特意避开孩子和孕妇，在家烟瘾犯了就去楼道或阳台吸烟。但是你知道吗？只要你还在抽烟，另一种更可怕的污染方式——“三手烟”，就会悄悄危害身边人的健康！

1、“三手烟”是什么？

“三手烟”是指吸烟者“吞云吐雾”后残留在衣物、墙壁、地毯、窗帘、皮革、家具，甚至头发和皮肤等表面的烟草烟雾残留物，是目前危害最为广泛的室内空气污染。

2、 抽烟没得肺癌 只是侥幸

研究证据表明：吸烟会大大提升肺癌风险！ 

肺癌是我国恶性肿瘤发病和死亡的首位原因，虽说肺癌的诱发因素多种多样，但吸烟和二手烟暴露是非常重要的一个致病因素。 2022年，中国肺癌发病人数106.06万，死亡人数73.33万，分别占全球肺癌发病和死亡的42.42%和40.73%。

很多疾病都与吸烟有着密不可分的关系，许多临床研究也验证了这一点——1支烟中含有3000多种化学物质，43种致癌物质，还有一氧化碳、尼古丁、烟焦油等。经常吸烟的人容易出现头痛头晕、失眠紧张和咽喉不适等症状，并且患上脑卒中、冠心病、心肌梗死等一系列疾病的概率比健康人要高出不少，甚至生育功能也会受损。

吸烟几乎对身体的各个器官都是百害而无一益。吸烟者的吸烟量越大、吸烟年限越长，罹患恶性肿瘤的风险就越高。吸烟不仅对自己造成危害，呼出的二手烟三手烟也可对周围人造成伤害。

3、三手烟可通过皮肤吸收，容易被忽略

与一手烟和二手烟主要通过呼吸道吸入不同，三手烟可通过多种途径危害人体健康，包括经呼吸道吸入肺部，或与被污染的物体表面接触后经手—口途径摄入，甚至经皮肤吸收进体内，其健康危害并不亚于一手烟和二手烟。研究表明，三手烟会诱导呼吸道和全身的炎症反应，引起糖类、脂肪和蛋白质三大营养物质的代谢异常，损害机体免疫功能，危害育龄期女性的生殖健康，影响子代生长发育等。此外，三手烟含有多种致癌成分，长期接触可能增加肺癌等疾病的发生风险。

4、怎样避免“三手烟”的危害？遗憾的是，通风、吸尘、空气净化器等一些常用方式，并不能够有效消除室内的三手烟。预防三手烟污染最有效的措施仍是在住宅内、车内和公共场所实施严格禁烟。

吸烟的家长应避免在家中或车内吸烟，吸烟后或二手烟暴露后，不宜直接与婴幼儿接触，应及时洗澡和更换衣物；吸烟者家中的窗帘、沙发、地毯、壁纸等容易吸附残留烟雾之处，应勤清洗和更换；在外出时尽量选择“禁止吸烟”的餐厅和其他室内场所，降低接触烟草的几率。
