# 【疫情防控】宁德市闽东医院金山门诊核酸采样点采样时间调整通知

> 更新时间：2026-09-16 (UTC+8)

为做好新冠肺炎疫情防控工作，满足疫情防控下社会个人或单位的核酸检测需求，宁德市闽东医院“愿检尽检”核酸采样点（宁德市闽东医院原金山门诊部福安市金山北路54号）从3月30日全面向社会提供24小时核酸检测采样服务，现将相关事项告知如下：

（一）提供服务对象：“愿检尽检”的单位或个人，（不包括：进口冷链食品监管和从业人员，集中隔离场所管理和服务人员，口岸进口货物直接接触人员，国际交通运输工具从业人员，船舶引航员等登临外籍船舶作业人员）。

健康码“黄码”/“红码”且无就医需求的请前往福安疫情指挥部指定地点采样检测——阳头社区核酸检测采样点（采样通道）。

（二）进入核酸采样点须正确佩戴口罩，出示健康码，并配合工作人员做好预检分诊、体温监测等工作，排队请保持一米距离。

（三）金山门诊核酸采样点实行“全预约制”，请根据提示预存费用。预约方式：1、可通过宁德市闽东医院APP或微信公众号进行线上预约；2、持本人社保卡/就诊卡和身份证现场预约。

为减少人员聚集及缩短排队时长，建议采取线上方式进行预约，详见《宁德市闽东医院新冠病毒核酸检测网上预约流程》。

（四）采样时间：周一至周日（含节假日）24小时开放。

（五）样本报告时间：

报告可在规定时间内于自助机打印或关注宁德市闽东医院APP/公众号查询。

（六）咨询电话：0593-6335196。

感谢您为新冠肺炎疫情防控工作付出的努力，因疫情防控给您带来的不便，敬请谅解！
